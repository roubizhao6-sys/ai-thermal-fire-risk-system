热感哨兵手机安装中心

把热感火警检测装到手机主屏幕

选择你的手机系统。无需 App Store 或 Apple 开发者账号，安装后会生成独立图标，并像普通 App 一样全屏打开。

iPhone / iPad 安装

推荐

下载安装描述文件，然后在“设置”中确认。该描述文件只会在主屏幕添加网站快捷方式，不会访问你的隐私数据。

下载手机安装配置
  1. 点击上方按钮，选择“允许”。
  2. 打开“设置 → 通用 → VPN与设备管理”。
  3. 点击“已下载的描述文件”，选择“安装”。
  4. 返回主屏幕，点击“热感哨兵”图标。

Android 安装

PWA

Android 无法安装 Mac 的 DMG 文件。请使用 Chrome 打开网页版并安装为 Web App。

打开网页并安装
  1. 使用 Chrome 打开网页。
  2. 点击右上角“⋮”菜单。
  3. 选择“安装应用”或“添加到主屏幕”。
  4. 确认后即可从主屏幕运行。

Mac 电脑安装

DMG

Mac 用户请下载完整原生 App，支持模拟热像仪、ESP32 串口和 Wi-Fi WebSocket。
