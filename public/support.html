SUPPORT

技术支持

● 当前优先支持模拟器与 ESP32 Wi-Fi WebSocket 接入

运行要求

macOS 14 或更高版本。首次打开 App 时，如 macOS 显示安全提示，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。

无硬件演示

打开 App 后默认使用内置模拟热像仪，可验证热成像矩阵、最高温度和风险分级功能。

ESP32 连接

  1. 确认 ESP32 与 Mac 位于同一局域网。
  2. 在 App 的“硬件连接”中选择“Wi-Fi WebSocket”。
  3. 输入设备地址，例如 ws://192.168.4.1:81/。
  4. 确认设备发送的数据符合 JSON 协议。

故障排查

  • 检查 ESP32 固件是否持续输出 JSON。
  • 检查 Mac 本地网络访问权限。
  • 检查 WebSocket 端口和 IP 地址。
  • 先切换模拟器，确认 App 本身正常运行。

联系与问题反馈

请通过 GitHub Issues 提交问题，并提供 macOS 版本、连接方式和错误提示。
